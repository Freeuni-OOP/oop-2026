--------------------------------------------------------

კონკურენტულობა:

ბიდის დადების დროს ვიყენებთ database transaction-ს.

1. იწყება transaction
2. SELECT auction FOR UPDATE
3. მოწმდება current_price
4. თუ ახალი ბიდი უფრო მაღალია:
      - ინახება bid
      - ახლდება auction.current_price
5. COMMIT

ამის შედეგად კონკრეტული აუქციონის ჩანაწერი იბლოკება
transaction-ის დასრულებამდე.

თუ ორი მომხმარებელი ერთდროულად ცდილობს ბიდის დადებას,
მეორე დაელოდება პირველის დასრულებას და შემდეგ
თავიდან შეამოწმებს ფასს.

ამიტომ შეუძლებელია ერთდროულად ორი გამარჯვებული ბიდის მიღება.

აუქციონის დასრულება:

AuctionFinishServlet (cron/job)

პერიოდულად ამოწმებს:

status = ACTIVE

თუ დასრულებულია:

1. პოულობს ყველაზე მაღალ ბიდს
2. winner_user_id ინახება auction-ში
3. სტატუსი ხდება FINISHED
4. იგზავნება შეტყობინება გამარჯვებულთან
